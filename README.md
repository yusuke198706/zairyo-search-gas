# 材料検索システム

**現役配電工事士が自社業務のために開発した、現場材料の検索・集計Webアプリ**

> "パターンとサイズを選ぶだけで、必要な材料と個数が自動で一覧化される"

---

## デモ

> **[デモ画面を見る](https://yusuke198706.github.io/zairyo-search-gas/demo.html)**

| 画面 | 説明 |
|------|------|
| カテゴリ選択 | 高圧・低圧などのカテゴリをタップ |
| パターン選択 | 工事パターン番号を選択 |

| 集計リスト | 複数パターンをまとめて合計集計・出力 |
| 逆引き検索 | 材料名のキーワードからパターンを逆引き |

## このプロジェクトについて

### 解決した課題

配電工事では工事パターンごとに必要な材料が決まっています。従来は：

- 工事パターンから材料を手動でリストアップ → **抜け漏れが多発**
- 複数パターンの材料を合算する作業が手間 → **集計ミスが起きやすい**
- 材料表を紙で管理 → **現場でのリアルタイム確認が困難**

### 実現したこと

**「カテゴリ → パターン → サイズの3ステップで必要材料が即表示される」** システムを構築。  
複数パターンの材料を自動集計し、コピー・印刷まで一気に完結。

---

## 主な機能

- **3ステップ検索** — カテゴリ → パターン → サイズで絞り込み
- **集計リスト** — 複数パターンを足し合わせて合計材料数を自動計算
- **逆引き検索** — 材料名のキーワードで使用パターンを検索
- **コピー & 印刷** — 結果をクリップボードコピーまたは印刷
- **オフライン対応** — 一度読み込んだデータをLocalStorageにキャッシュ
- **データ同期** — 「同期」ボタンでGoogleスプレッドシートから最新データを取得
- **スマホ最適化** — モバイルファーストのレスポンシブデザイン（スマホ画面に最適化）

## スプレッドシートの構成

`シート2` に以下の形式で材料マスタを登録：

| A列（pattern） | B列（wire size） | C列（カテゴリ） | D列（material1） | E列（数量） | F列（material2） | G列（数量） | … |
|--------------|----------------|--------------|----------------|------------|----------------|------------|---|
| パターン11 | 25SQ | 高圧 | アームタイ1000 | 1 | 単バンド175 | 1 | … |

| シート名 | 用途 |
|----------|------|
| シート2  | 材料マスターデータ |
| Log      | 検索ログ（日時・件数・ユーザー） |

## セットアップ方法

### 前提

- Google アカウント
- [clasp](https://github.com/google/clasp)（ローカルで管理する場合のみ）

### 手順

#### 1. スプレッドシートを準備

上記の形式で `シート2` に材料マスタを入力してください。

#### 2. GASへのコードを貼り付け

1. スプレッドシートを開く
2. `拡張機能` → `Apps Script` を開く
3. `コード.js` の内容を貼り付け
4. `コード.js` 1行目の `SPREADSHEET_ID` を自分のスプレッドシートIDに変更
5. `index.html` の内容を HTMLファイルとして貼り付けて保存

#### 3. Webアプリとしてデプロイ

1. GAS エディタで「デプロイ」→「新しいデプロイ」
2. 種類：**ウェブアプリ**
3. アクセスできるユーザー：**全員**（または組織内）
4. デプロイして発行されたURLをスマートフォンでブックマーク

#### 4. clasp でローカル管理（任意）

```bash
npm install -g @google/clasp
clasp login
clasp clone <スクリプトID>
# コード変更後はpush
clasp push
```

## 使い方

1. デプロイしたURLをスマートフォンでブックマーク（またはホーム画面に追加）
2. カテゴリをタップ（高圧・低圧 など）
3. 工事パターンをタップ
4. 電線サイズをタップ
5. 必要材料リストが表示される
6. 「集計リストに追加」で複数パターンを積み上げ
7. 集計タブで合計を確認・コピー・印刷

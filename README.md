# 材料検索システム

配電工事の現場で使う**材料リスト自動生成ツール**です。  
Google Apps Script (GAS) で動作し、スマートフォンからカテゴリ → パターン → サイズの3ステップで必要材料を即検索できます。

---

## デモ

> **[デモ画面を見る](https://yusuke198706.github.io/zairyo-search-gas/demo.html)**

| 画面 | 説明 |
|------|------|
| カテゴリ選択 | 高圧・低圧などのカテゴリをタップ |
| パターン選択 | 工事パターン番号を選択 |
| サイズ選択 | 電線サイズ（SQ）を選択 |
| 結果表示 | 必要材料リストを表示・コピー・印刷 |
| 集計リスト | 複数パターンをまとめて集計・出力 |
| 逆引き検索 | 材料名からパターンを逆引き |

---

## 機能

- **3ステップ検索** — カテゴリ → パターン → サイズで絞り込み
- **集計リスト** — 複数パターンを足し合わせて合計材料数を自動計算
- **逆引き検索** — 材料名のキーワードで使用パターンを検索
- **コピー & 印刷** — 結果をクリップボードコピーまたは印刷
- **オフライン対応** — 一度読み込んだデータをLocalStorageにキャッシュ
- **データ同期** — 「同期」ボタンでGoogleスプレッドシートから最新データを取得
- **スマホ最適化** — モバイルファーストのレスポンシブデザイン

## セットアップ

### 前提

- Google アカウント
- [Node.js](https://nodejs.org/) (clasp使用時)
- [clasp](https://github.com/google/clasp) インストール済み

### 手順

#### 1. スプレッドシートを準備

Google スプレッドシートに **「シート2」** を作成し、以下の列形式でデータを入力します。

| pattern | wire size | カテゴリ | material1 | 数量 | material2 | 数量 | … |
|---------|-----------|----------|-----------|------|-----------|------|---|
| パターン11 | 25SQ | 高圧 | アームタイ1000 | 1 | … | … | … |

#### 2. GAS プロジェクトを作成

1. [Google Apps Script](https://script.google.com/) を開く
2. 新しいプロジェクトを作成
3. `コード.js` の内容を貼り付け
4. `コード.js` 1行目の `SPREADSHEET_ID` を自分のスプレッドシートIDに変更
5. `index.html` の内容を HTMLファイルとして貼り付け

#### 3. Webアプリとしてデプロイ

1. GAS エディタで「デプロイ」→「新しいデプロイ」
2. 種類：**ウェブアプリ**
3. アクセスできるユーザー：**全員**（または組織内）
4. デプロイして発行されたURLをブックマーク

#### 4. clasp でローカル管理（任意）

```bash
npm install -g @google/clasp
clasp login
clasp clone <スクリプトID>
# コード変更後はpush
clasp push
```

## Googleスプレッドシート設定

| シート名 | 用途 |
|----------|------|
| シート2  | 材料マスターデータ |
| Log      | 検索ログ（日時・件数・ユーザー） |

---

## 使い方

1. デプロイしたURLをスマートフォンでブックマーク（またはホーム画面に追加）
2. カテゴリをタップ
3. 工事パターンをタップ
4. 電線サイズをタップ
5. 必要材料リストが表示される
6. 「集計リストに追加」で複数パターンを積み上げ
7. 集計タブで合計を確認・コピー・印刷
